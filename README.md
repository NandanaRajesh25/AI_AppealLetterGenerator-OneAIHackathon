# AI Appeal Letter Generator 📝  

A Streamlit app that generates professional **insurance appeal letters** using **Google’s Generative AI (Gemini)**. It simplifies the process of appealing claim denials with automation, analysis, and structured outputs.  

---

## Features 🌟  

### 📂 Document Processing  
- Supports **PDF, TXT, and Images (with OCR)**  
- Automated text extraction & validation  

### 🔍 Smart Extraction  
- Extracts **patient info, denial reasons, insurance details**  
- Generates **claim summary** & calculates **appeal deadlines**  

### 🤖 AI-Powered Analysis  
- Classifies **denial reasons** (e.g., Not Medically Necessary, Out of Network, etc.)  
- Generates **professional appeal letters**  
- Provides **explanations, risk assessment & success prediction**  

### 💻 User-Friendly Interface  
- Step-by-step workflow with **status indicators**  
- Expandable review sections for easy verification  
- Checklist for required attachments  

---

## Tech Stack ⚡  
- **Frontend**: Streamlit  
- **Backend**: Python  
- **AI Model**: Google Gemini (Generative AI)  
- **OCR**: Tesseract
